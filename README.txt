NIGHT FRONT — OXIDE / NFT V3
Мобільний PWA-сайт клану.

1. Замініть DISCORD_INVITE у app.js на реальне Discord-посилання.
2. Завантажте всю папку на HTTPS-хостинг (GitHub Pages, Netlify, Vercel тощо).
3. Відкривайте сайт зі смартфона.
4. PWA можна встановити через меню браузера «Додати на головний екран».

На ПК сайт навмисно показує mobile-only екран.
